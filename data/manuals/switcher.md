# NorthLight NL-4 Production Switcher

Made-up sample manual for a demo. Not a real product.

## Overview

The NL-4 is a four mix-effects production switcher for live broadcast. Each mix-effects bank has eight keyers. The switcher accepts up to 96 inputs and drives 48 outputs. A single NL-4 frame supports formats up to 2160p at 59.94 frames per second.

## Transitions

A transition moves the program output from one source to another. The NL-4 supports cut, mix, wipe and DVE transitions. The default mix rate is 30 frames. Press AUTO TRANS to run a transition at the stored rate, or move the fader bar for a manual transition.

## Keyers

Keyers layer graphics or video over the background. The NL-4 offers luma keys, chroma keys and linear keys. The chroma keyer has automatic spill suppression. Up to eight keyers are available on every mix-effects bank.

## Memory

Memories store the full state of a mix-effects bank. The NL-4 holds 100 memories per bank. Recall a memory from the control panel or with the memory recall command over the automation protocol.

## Redundancy

The NL-4 frame has two hot-swappable power supplies. If one supply fails the frame keeps running on the other and raises a power alarm. The control processor can be fitted with an optional backup card that takes over within two frames.

## Troubleshooting

If the program output freezes, check the reference signal first. The NL-4 must be locked to black burst or tri-level sync. A blinking REF light on the front panel means the frame has lost reference.
